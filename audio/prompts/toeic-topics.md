# TOEIC Part 2/3/4 の題材バンク

TOEIC は特定分野の専門知識を測る試験ではない。日常的なビジネス・生活の場面で
交わされるやり取りを聴き取れるかを測る。したがって Part 2/3/4 の題材は
**資料（コースの章内容）に縛られない。** 資料の話題（論理回路、アルゴリズムなど）を
そのまま会話の題材にしない — 実際の TOEIC には出ない話題だから。

資料と紐付けるのは `vocabulary`（`--vocab-deck` で渡された語彙）を自然に混ぜる場合だけ。
題材そのものは以下のシナリオ分類から選ぶ。

## シナリオ分類

実際の TOEIC で繰り返し使われる場面。1問（1 item）につき1つを選び、その場面の中で
用件が完結する会話・説明文にする。

| 分類 | 典型的な場面 |
|---|---|
| オフィス業務 | 予定変更、資料の確認依頼、承認待ち、経費精算、給与・昇給の相談 |
| 人事 | 採用面接、研修の案内、異動の連絡、勤務シフトの調整 |
| 店舗・小売 | 注文の変更、返品対応、在庫確認、レジ・会計のトラブル |
| 飲食・イベント | 予約の調整、ケータリングの手配、会場設営 |
| ホテル・宿泊 | チェックイン/アウトの問題、予約変更、部屋の設備トラブル |
| 出張・移動 | フライト/電車の遅延、レンタカー、経路の確認 |
| 倉庫・物流 | 出荷ミス、在庫管理、配送遅延、フォークリフト・搬入 |
| 設備・IT | 社内システムの不具合、機器の修理依頼、ソフトウェア研修 |
| 建築・不動産 | オフィス改装、物件の内見、賃貸契約の確認 |
| 製造・品質 | 生産ラインの問題、安全点検、品質検査の報告 |
| 広告・マーケティング | 新商品の紹介、キャンペーンの相談、市場調査の結果報告 |
| 医療・窓口 | 診察予約、検査結果の説明（Part 4 のアナウンス向き） |
| 公共放送 | 館内放送、交通機関の案内、天気・ニュース速報（Part 4 向き） |

## 使い方

- **1問1シナリオ。** 分類をまたいで話題を混ぜない。
- 資料の分野知識は前提にしない。学習者が今どの科目を勉強していても解ける題材にする。
- 固有名詞・会社名は使わない（TOEIC 本番も一般名で通す: "the sales team", "our supplier" 等）。
- `vocabulary` に専門語が渡された場合だけ、上記シナリオの自然な文脈に紛れ込ませる
  （例: `latency` を「IT システムの不具合」報告の会話に使う）。無理にシナリオ自体を
  専門分野に寄せない。

## 出典

シナリオ分類は ETS 公式サンプル問題・大手 TOEIC 対策サイト（EF, Lingomelo, 990prep 等）
が挙げる頻出場面の要約に基づく。個別の会話文はこのファイルには含めない
（そのまま複製すると出典記事の文章の丸写しになるため、場面設定だけを参考にして
その都度新しく書く）。
